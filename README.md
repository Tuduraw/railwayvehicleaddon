# Tudur's Vehicle Mod: Railway Addon

> このMODのコードおよびドキュメントの生成には、AnthropicのClaudeを使用しています。

[Tudur's Vehicle Mod](https://github.com/Tuduraw/tudursvehiclemod)(以下、前提MOD)に
鉄道車両と、曲線・勾配を自動生成する独自の線路システムを追加するアドオンMODです。

現在は **フェーズ1〜2の途中**(線路の敷設・撤去・描画、分岐器・渡り線・転車台・遷車台・車止め、単車の走行)の段階です。

- Minecraft 1.21.11 / Fabric Loader 0.18.2 以上 / Fabric API 0.139.4+1.21.11
- 前提MOD: tudursvehiclemod 1.0.3 以上

---

## ビルド

1. 前提MODのディレクトリで `./gradlew publishToMavenLocal` を実行し、ローカルMavenへ公開します。
2. このMODのディレクトリで `./gradlew build` を実行します。

前提MODのバージョンは `gradle.properties` の `tudursvehiclemod_version` で指定します。

## 線路の敷設(測量ツール)

クリエイティブタブ「鉄道」の **測量ツール** を使います。ツールには用途別のモードがあり、
**Z** キーで切り替えます(スニーク中は逆順)。現在のモードと状態はアクションバーに表示されます。

### 共通の操作

| 操作 | 内容 |
|---|---|
| 右クリック(ブロック) | 点を追加(最大160ブロック先まで狙えます) |
| 右クリック(点を狙う) | その点を選択/解除(最大2点。選択中は白枠) |
| 1点選択中に右クリック(ブロック) | 選択した点をその位置へ移動 |
| 隣り合う2点選択中に右クリック(ブロック) | 2点の間に点を挿入(新規生成モードのみ) |
| スニーク+右クリック | 選択を解除。選択が無ければ最後の点(または環状)を取り消し |
| Delete | 狙っている点を削除。狙っていなければ選択中の点を削除 |
| Enter | 確定 |
| Backspace | 点をすべて消去 |
| [ / ] | モード固有のパラメータを増減(使うモードのみ) |
| 右クリック(分岐器を狙う) | 分岐器の開通方向を切り替え |

キーはいずれも操作設定の「鉄道アドオン」から個別に変更できます。点を置く・動かすたびに
プレビューが更新されるので、見ながら調整できます。

- **緑の線**: 敷設可能な経路 / **赤い線・赤枠**: 曲線半径や勾配に問題がある箇所
- **青枠**: 点(最初の点は大きめ) / **紫枠**: 既存線路の端に接続する点 / **オレンジ枠**: 狙っている点
- **赤く塗られたブロック**: 自動で撤去できないブロック(水・溶岩などの流体、非常に硬いブロック、未ロードの範囲)。1つでもあると敷設できません
- **黄色く塗られたブロック**: 自然の地形ではない(プレイヤーが設置したとみなす)ブロック。警告のみで敷設は可能です
- **水色の枠と線**: 分岐器と、現在開通している方向
- **オレンジの円**: 狙っている転車台・遷車台(右クリックで動かせます)

確定すると、線路の建築限界(既定では線路中心から左右1.5、線路面から高さ4.0)に入るブロックは
自動で撤去されます。盛土・橋脚などの地形の加工は行いません。

### 新規生成モード(既定)

点を順に結んで1本の路線を作ります。曲線は経由点を必ず通り、経由点の前後でも曲がり具合
(カント)が連続するように生成されます。経由点の間は一定勾配で、勾配の変わり目には縦曲線が入ります。

- 最初の点を既存線路の **端** の近く(1.5ブロック以内)に置くと、その端から向きを揃えて延伸します
- 最後の点を既存線路の端の近くに置くと、その端へ向きを揃えて接続します
- 3点以上置いたあとで **最初の点をもう一度狙って右クリック** すると環状線になります
  (既存線路に接続している場合は不可)

### 分岐生成モード

1. 分岐元を指定します。既存線路の **端** でも **途中** でも構いません
2. 続けて分岐先を指定します。各分岐先へ1本ずつ線路が伸びます。
   分岐先に既存線路の端を指定すると、そこへ接続します

- **端から分岐**: 分岐先は2つ以上。開通方向の初期値は2点目への線路です
- **途中から分岐**: その地点で線路を分割して分岐器を入れます。分岐先は1つ以上で、元の線路の
  続きも分岐の1本になります(開通方向の初期値は元の線路の続き)。分岐する向きは最初の分岐先の
  方向で決まり、分岐先はすべて同じ向きの側に置きます

分岐した線路は元の線路と同じ向きから始まるので、分岐器の前後で線路の向きが連続します。
分岐側から進入した列車は、開通方向に関係なく元の線路へ進みます。分岐器は、どのモードでも
測量ツールで狙って右クリックすると切り替わります。

### 渡り線モード

並んだ2本の線路の上をそれぞれ1点ずつ指定すると、両方の線路に分岐器を入れ、その間をS字の
連絡線でつなぎます。2本の線路の向きの差は30°以内である必要があります。

### 転車台モード

1. 1点目・2点目で桁の両端(直径)を指定します。中点が回転の中心になります。
   既存線路の端を指定すると、その線路に直接つながります(線路の端が転車台の方を向いている必要があります)
2. 3点目以降で、接続部を増やしたい方向を指定します。1点目の方向から、[ ] キーで選んだ
   角度刻み(5〜90°)に丸めた方向に接続部ができます。扇形機関庫のような放射状の配置にできます

1点目・2点目だけなら、その2か所だけを接続します。新しく作った接続部には外向きに3ブロックの
短い線路が付くので、そこから新規生成モードで延伸してください。

**操作**: 測量ツールで転車台を狙って右クリックすると次の接続部へ、スニーク+右クリックで前の
接続部へ回転します。桁の上の車両は桁と一緒に回ります。回転中は桁の端で線路が途切れるため、
車両は出入りできません。桁と周りの線路にまたがっている車両があると回転しません。

### 遷車台モード

1. 1点目・2点目で桁の両端を指定します(既存線路の端を指定するとそこへ接続)
2. 3点目以降で、桁を平行移動させて止める位置を指定します。桁と直角の方向の距離が、[ ] キーで
   選んだ間隔(2〜10ブロック)に丸められます

各停止位置の両端に接続部(外向きの短い線路)ができます。操作は転車台と同じです。

### 車止めモード

線路の端を指定すると車止めを置きます。車両は端の2.5ブロック手前で止まります。
車止めのある端からは延伸できません(撤去モードで車止めを撤去してから延伸します)。

### 撤去モード

撤去したい区間や設備を右クリックで選択し(赤で表示)、Enterでまとめて撤去します。
スニーク+右クリックで選択をすべて解除します。転車台・遷車台の桁や接続用の短い線路を選ぶと、
設備ごと撤去されます。

## 鉄道車両

「鉄道車両」スポーンアイテム(T1〜T5)で、前提MODと同じ車両選択画面から呼び出せます。
線路の近く(6ブロック以内)に呼び出すと自動で線路に載ります。向きは呼び出したときの
プレイヤーの向きに近い方になります。

- W / S: スロットル(前進・後退)
- ブレーキ: 前提MODのブレーキキー
- 運転者がいない車両は停止保持されます
- 線路の端(車止め)で停止します

テスト用に `Sample Railcar`(`railwayvehicleaddon:sample_railcar`)を同梱しています。

### 車両JSONの `rail` オブジェクト

前提MODの車両JSONに `rail` オブジェクトを追加すると、鉄道車両固有の設定になります
(前提MODの読み込みは未知のキーを無視するため、同じファイルに書けます)。
`entity_type` は `railwayvehicleaddon:rail_vehicle` を指定してください。

```json
"entity_type": "railwayvehicleaddon:rail_vehicle",
"rail": {
  "bogies": [
    { "part": "$bogie_front", "pivot_x": 0.0, "pivot_y": 0.35, "pivot_z": 3.2 },
    { "part": "$bogie_rear",  "pivot_x": 0.0, "pivot_y": 0.35, "pivot_z": -3.2 }
  ],
  "traction": 0.004,
  "brake": 0.015,
  "resistance": 0.0003,
  "grade_gravity": 0.04
}
```

| 項目 | 既定値 | 説明 |
|---|---|---|
| `bogies` | 空 | 台車。`pivot_z` が最大のものを前台車、最小のものを後台車として線路に載せます(`pivot_z`×`scale`が線路上の位置)。`part` を指定するとそのOBJグループがカーブで回転します。省略時は前後±1ブロックで線路に載せます |
| `traction` | 0.004 | スロットル100%時の加速度(ブロック/tick²) |
| `brake` | 0.015 | ブレーキ時の減速度(ブロック/tick²) |
| `resistance` | 0.0003 | 走行抵抗による減速度(ブロック/tick²) |
| `grade_gravity` | 0.04 | 勾配にかかる重力加速度。勾配を掛けた分が加減速になります |

最高速度は前提MODの `max_speed`(ブロック/tick)が使われます。モデルは原点を
**レール上面**、前方を **+Z** として作成してください。

## 設定(`config/railwayvehicleaddon.json`)

サーバー側の値がログイン時にクライアントへ送られ、プレビューにも使われます。

| 項目 | 既定値 | 説明 |
|---|---|---|
| `gauge` | 1.435 | 軌間(ブロック) |
| `min_curve_radius` | 12.0 | 最小曲線半径 |
| `max_grade` | 0.1 | 最大勾配(0.1 = 100‰) |
| `vertical_curve_length` | 16.0 | 縦曲線の長さ(0で縦曲線なし) |
| `clearance_half_width` | 1.5 | 建築限界の片側幅 |
| `clearance_height` | 4.0 | 建築限界の高さ |
| `unbreakable_hardness` | 30.0 | この硬度以上のブロックは自動撤去不可(黒曜石=50、古代の残骸=30) |
| `design_speed_kmh` | 80.0 | カント計算に使う設計速度。低くするとゆるい曲線のカントが小さくなります |
| `cant_transition_length` | 16.0 | カントの逓減長。直線や別の曲線とのつなぎ目で、カントをこの長さをかけて滑らかに変化させます |
| `max_waypoints` | 64 | 1回の敷設の最大経由点数 |
| `max_route_length` | 2048.0 | 1回の敷設の最大延長 |
| `drop_removed_blocks` | `player_placed` | 撤去したブロックのドロップ(サバイバル時のみ): `none` / `player_placed` / `all` |

### 自然地形の判定

自然の地形とみなすブロックはブロックタグ `railwayvehicleaddon:natural_terrain` で
定義しています。データパックで追加・変更できます。村などの生成構造物に使われている
木材やレンガは「設置物」として警告されます(敷設は可能です)。

## フェーズ1の制限事項

- 信号・編成(連結)・自動運転は未対応です
- チャンクの強制ロードは未実装です(編成を扱うフェーズ2で、動作中の編成全体と前方を強制ロードする方式で実装予定)
- 敷設・撤去の対象はロード済みの範囲に限られます
- 既存線路の端に接続した箇所には縦曲線が入らず、勾配が異なると折れ角が残ります
- 列車とエンティティの衝突判定はありません(すり抜けます)
- バニラのレール・トロッコとの互換はフェーズ3で対応予定です
