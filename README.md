# Tudur's Vehicle Mod: Railway Addon

> このMODのコードおよびドキュメントの生成には、AnthropicのClaudeを使用しています。

[Tudur's Vehicle Mod](https://github.com/Tuduraw/tudursvehiclemod)(以下、前提MOD)に
鉄道車両と、曲線・勾配を自動生成する独自の線路システムを追加するアドオンMODです。

現在は **フェーズ1〜2の途中**(線路の敷設・撤去・描画、分岐器・渡り線・転車台・遷車台・車止め、単車の走行)の段階です。

- Minecraft 1.21.11 / Fabric Loader 0.18.2 以上 / Fabric API 0.139.4+1.21.11
- 前提MOD: tudursvehiclemod 1.0.3 以上

---

## ビルド

1. 前提MODのディレクトリで `./gradlew publishToMavenLocal` を実行し、ローカルMavenへ公開します。
2. このMODのディレクトリで `./gradlew build` を実行します。

前提MODのバージョンは `gradle.properties` の `tudursvehiclemod_version` で指定します。

## 線路の敷設(測量ツール)

クリエイティブタブ「鉄道」の **測量ツール** を使います。ツールには用途別のモードがあり、
**Z** キーで切り替えます(スニーク中は逆順)。現在のモードと状態はアクションバーに表示されます。

### 共通の操作

| 操作 | 内容 |
|---|---|
| 右クリック(ブロック) | 点を追加(最大160ブロック先まで狙えます) |
| 右クリック(点を狙う) | その点を選択/解除(最大2点。選択中は白枠) |
| 1点選択中に右クリック(ブロック) | 選択した点をその位置へ移動 |
| 隣り合う2点選択中に右クリック(ブロック) | 2点の間に点を挿入(新規生成モードのみ) |
| スニーク+右クリック | 選択を解除。選択が無ければ最後の点(または環状)を取り消し |
| Delete | 狙っている点を削除。狙っていなければ選択中の点を削除 |
| Enter | 確定 |
| Backspace | 点をすべて消去 |
| [ / ] | モード固有のパラメータを増減(使うモードのみ) |
| I | 敷設する線路の道床を切り替え(砕石 → 土 → 道床なし) |
| スニーク+I | 敷設する線路の電化方式を切り替え(非電化 → 架線 → 第三軌条 → 非表示) |
| Home | 強制置換の切り替え(クリエイティブのみ) |
| 右クリック(分岐器を狙う) | 分岐器の開通方向を切り替え |

キーはいずれも操作設定の「鉄道アドオン」から個別に変更できます。点を置く・動かすたびに
プレビューが更新されるので、見ながら調整できます。

- **緑の線**: 敷設可能な経路 / **赤い線・赤枠**: 曲線半径や勾配に問題がある箇所
- **青枠**: 点(最初の点は大きめ) / **紫枠**: 既存線路の端に接続する点 / **オレンジ枠**: 狙っている点
- **赤く塗られたブロック**: 自動で撤去できないブロック(水・溶岩などの流体、非常に硬いブロック、未ロードの範囲)。1つでもあると敷設できません
- **黄色く塗られたブロック**: 自然の地形ではない(プレイヤーが設置したとみなす)ブロック。警告のみで敷設は可能です
- **水色の枠と線**: 分岐器と、現在開通している方向。敷設済みの線路でも、分岐部では開通している
  方向のレールだけがつながって表示されます
- **オレンジの円**: 狙っている転車台・遷車台(右クリックで動かせます)

確定すると、線路の建築限界(既定では線路中心から左右1.5、線路面から高さ4.0)に入るブロックは
自動で撤去されます。盛土・橋脚などの地形の加工は行いません。

確定に失敗した場合(未ロードの範囲を含む、確定までの間にブロックが変わった等)は、点はそのまま
残るので、手直しして再度確定できます。点は成功したときだけ消えます。

**道床**: I キーで、これから敷設する線路の道床(砕石・土・道床なし)を選べます。道床は区間ごとに
保存され、あとから敷設する線路の選択には影響しません。

**電化方式**: スニーク+I キーで、これから敷設する線路の電化方式(非電化・架線・第三軌条・非表示)を選べます。
道床と同じキーで、スニークの有無だけで切り替え先が変わります。架線・第三軌条のどちらでも、電車への
給電としては区別しません(違いは見た目だけです)。詳しくは後述の「電化モード」を参照してください。

**強制置換**(クリエイティブのみ): Home キーで有効にすると、本来は撤去できない水・溶岩や非常に
硬いブロック(岩盤など)を含む経路でも敷設でき、それらのブロックも撤去されます(プレビューでは
桃色で表示)。未ロードの範囲は書き換えられないため、強制置換でも敷設できません。周囲の水や
溶岩は撤去した範囲へ流れ込むことがあります。

### 新規生成モード(既定)

点を順に結んで1本の路線を作ります。曲線は経由点を必ず通り、経由点の前後でも曲がり具合
(カント)が連続するように生成されます。経由点の間は一定勾配で、勾配の変わり目には縦曲線が入ります。

- 最初の点を既存線路の **端** の近く(1.5ブロック以内)に置くと、その端から向きを揃えて延伸します
- 最後の点を既存線路の端の近くに置くと、その端へ向きを揃えて接続します
- 3点以上置いたあとで **最初の点をもう一度狙って右クリック** すると環状線になります
  (既存線路に接続している場合は不可)

### 分岐生成モード

1. 分岐元を指定します。既存線路の **端** でも **途中** でも構いません
2. 続けて分岐先を指定します。各分岐先へ1本ずつ線路が伸びます。
   分岐先に既存線路の端を指定すると、そこへ接続します

- **端から分岐**: 分岐先は2つ以上。開通方向の初期値は2点目への線路です
- **途中から分岐**: その地点で線路を分割して分岐器を入れます。分岐先は1つ以上で、元の線路の
  続きも分岐の1本になります(開通方向の初期値は元の線路の続き)。分岐する向きは最初の分岐先の
  方向で決まり、分岐先はすべて同じ向きの側に置きます

分岐した線路は元の線路と同じ向きから始まるので、分岐器の前後で線路の向きが連続します。
分岐側から進入した列車は、開通方向に関係なく元の線路へ進みます。分岐器は、どのモードでも
測量ツールで狙って右クリックすると切り替わります。

### 渡り線モード

並んだ2本の線路の上をそれぞれ1点ずつ指定すると、両方の線路に分岐器を入れ、その間をS字の
連絡線でつなぎます。2本の線路の向きの差は30°以内である必要があります。

### 転車台モード

1. 1点目・2点目で桁の両端(直径)を指定します。中点が回転の中心になります。
   既存線路の端を指定すると、その線路に直接つながります(線路の端が転車台の方を向いている必要があります)
2. 3点目以降で、接続部を増やしたい方向を指定します。1点目の方向から、[ ] キーで選んだ
   角度刻み(5〜90°)に丸めた方向に接続部ができます。扇形機関庫のような放射状の配置にできます

1点目・2点目だけなら、その2か所だけを接続します。新しく作った接続部には外向きに3ブロックの
短い線路が付くので、そこから新規生成モードで延伸してください。

**操作**: 測量ツールで転車台を狙って右クリックすると次の接続部へ、スニーク+右クリックで前の
接続部へ回転します。桁の上の車両は桁と一緒に回ります。回転中は桁の端で線路が途切れるため、
車両は出入りできません。桁と周りの線路にまたがっている車両があると回転しません。

### 遷車台モード

1. 1点目・2点目で桁の両端を指定します(既存線路の端を指定するとそこへ接続)
2. 3点目以降で、桁を平行移動させて止める位置を指定します。桁と直角の方向の距離が、[ ] キーで
   選んだ間隔(2〜10ブロック)に丸められます

各停止位置の両端に接続部(外向きの短い線路)ができます。操作は転車台と同じです。

### 車止めモード

線路の端を指定すると車止めを置きます。車両は端の2.5ブロック手前で止まります。
車止めのある端からは延伸できません(撤去モードで車止めを撤去してから延伸します)。

### 撤去モード

撤去したい区間や設備を右クリックで選択し(赤で表示)、Enterでまとめて撤去します。
スニーク+右クリックで選択をすべて解除します。転車台・遷車台の桁や接続用の短い線路を選ぶと、
設備ごと撤去されます。

### 電化モード

敷設済みの区間を右クリックで選び(水色)、Enterで電化方式を適用します。適用する方式は、新規生成
モードと同じスニーク+I キーで(非電化・架線・第三軌条・非表示の順に)切り替えます。選んだ区間が全部すでに
その方式になっていれば、代わりに非電化へ戻します(同じ方式をもう一度選べば切り替わる、トグルの
操作感です)。これから敷設する線路も、スニーク+I キーで電化方式を選んでから敷設できます。

- **架線**: 線路の真上にトロリ線が張られ、12ブロックごとに架線柱と腕金(カンチレバー)が立ちます
- **第三軌条**: 走行レールの脇、一段低い位置に導体レールが這い、3ブロックごとに碍子(支持架)が立ちます
- **非表示**: 電化区間として給電の対象にはなりますが、架線も第三軌条も描きません。ブロックや別のmodで
  設備(架線柱・変電設備の見た目など)を自分で再現したいときに使います

どちらも建築限界の内側に収まります。架線・第三軌条のどちらでも、電車への給電としては区別しません
(集電方式に関わらず、電化されていれば給電を受けられます)。

### 連結モード

線路装置(下記)の連結先を付け替えます。装置を右クリックで選び(白枠)、続けて連結先を
右クリックします。選んだ装置が連結できる種類の対象だけが狙えます。スニーク+右クリックで
選択を解除します。どのモードでも、測量ツールを持って装置を見ると連結先が線で表示されます。

## 連結(編成)

隣り合う車両の端どうしが触れると、自動的に連結します(実物の自動連結器のような気軽さを優先し、
特別な操作は不要です)。連結を外すには、測量ツールを持って車両を右クリックします(プレイヤーに
近い方の端が外れます)。通常の右クリック(乗車)やスニーク+右クリック(前提MODの収納)とは衝突しません。

- **編成としての走行**: 連結された車両群は1つの剛体のように動きます。先頭車(運転者がいればその車両、
  いなければ最も若い内部IDの車両)が編成全体の速度を1回だけ計算し、各車両はその位置からの
  一定距離(連結時の車間)を保って追従します。曲線や勾配の途中でも車間は一定のままです
- **動力車**: 運転席(座席定義の`driver`が`true`)を持つ車両だけが動力車として扱われます。運転席の
  無い車両(客車・貨車・砲車)は、座席0に乗っても運転できず、編成では重さだけが加わります
- **編成の加速**: 動力車の(`acceleration` × `mass`)の合計を全車両の`mass`の合計で割った値が、
  編成全体の追従度になります。目標速度は、力行中の動力車の目標速度(スロットル×最高速度)を
  同じ重みで平均したものです。重い客車・貨車をつなぐほど加速が鈍り、動力車を増やすと回復します
- **ブレーキ**: 編成内のどの車両でもブレーキを掛けると、編成全体が減速します(実物の自動空気
  ブレーキのように、編成全体に効くという扱いです)。運転者が誰もいない編成は常にブレーキが掛かります
- **動力**: 各車両は、自分がいる位置(石炭の有無・電化区間の給電)で自分の動力を判定します。例えば
  電化されていない区間にいる電気機関車は、編成の中にいてもその時点では力行に寄与しません
- **向き**: 車両を前後逆向き(車首が逆)に連結することもできます(重連の机付け替えなど)。連結した
  瞬間の向きで固定されるので、連結後に向きが変わることはありません
- **連結器の位置**: `coupler_front`/`coupler_rear`を指定した車両では、その位置(車体の実際の前後端が
  一般的)を連結器として使います。未指定の車両は台車の位置がそのまま連結器になるため、台車より
  車体が張り出している車両どうしを連結すると、車体が重なって見えることがあります。同梱のテスト
  車両4両にはすべて指定済みです
- **台枠の長さが違う車両どうし**: 連結器の位置(`coupler_front`/`coupler_rear`、未指定なら台車の位置)
  を基準に車間を計算するので、長さの異なる車両を混結しても車間は正しく計算されます

### 制限事項

- 分割・解放は1両ずつです(編成の途中から一括で切り離す操作はありません)
- 推進運転(後ろの機関車で押す)はできます(前後どちらの車両が動力車でも力行できます)が、
  先頭車の運転台からの一括制御(総括制御)という形ではなく、各動力車の運転者がそれぞれ操作します
- 脱線・連結器の破断は再現していません

## 武装(装甲列車・列車砲)

前提MODの武装(`weapons`)と武器連動パーツ(`weapon_parts`)は、鉄道車両でもそのまま使えます。武器の
設定ファイル(`assets/<namespace>/weapons/*.txt`)・発射音(`sounds/*.ogg`)の置き場所も前提MODと同じです。
テスト用に次の2両を同梱しています。

| 車両 | 内容 |
|---|---|
| `railwayvehicleaddon:sample_armored_railcar` | 自走できる装甲軌道車(気動車、前進5・後進1ノッチ)。座席0が運転席、座席1が全周旋回の砲塔(76mm砲)、座席2が後部機銃(後方±70度) |
| `railwayvehicleaddon:sample_railway_gun` | 動力の無い列車砲(重さ4.0)。機関車に連結して運びます。座席0が照準手(280mm砲、左右±10度・仰角50度まで、着弾予測距離を表示)、座席1が乗員 |

列車砲は左右に10度しか向けられないため、転車台や曲線で車両ごと向きを変えて狙うのが前提です。

### 鉄道車両で武装を使うときの注意

調査の結果、前提MODの武装の仕組みは車両の種類に依存しない共通処理(発射・装填・冷却・砲塔の追従・
反動による砲身の後退)で動いており、鉄道車両でも基本的にそのまま動作します。ただし、このアドオンの
実装との違いから、次の点に注意が必要です。

- **運転席の照準付き武器**: 鉄道車両は視点を車両の向きに連動させるため、前提MODの航空機と同じ扱い
  (`FreeCameraVehicle`)になっています。この扱いでは、運転者は「視点で操縦している」とみなされ、
  フリールック中でない限り、運転席(座席0)の照準付き武器は既定の向きに固定されます。運転者にも砲を
  照準させたい場合は、車両JSONに `"default_freelook": true` を指定してください(運転者の視点が既定で
  自由になり、フリールックキーを押している間だけ車両の向きに固定されます)。砲手席(座席1以降)は
  この影響を受けず、常に自由に照準できます。同梱の装甲軌道車も、武器はすべて砲手席に載せています
- **運転席の無い車両(客車・砲車など)**: 座席0の乗員も含めて全員が常に自由に照準・見回しできます
- **車体の揺れ(武器の`Recoil`)**: 鉄道車両は線路の傾きから毎tick姿勢を決め直すため、前提MODの
  「発砲時に車体を揺らす」処理が正しく表現されません。鉄道車両の武器では`Recoil = 0`を推奨します。
  砲身の後退は、機体側の`weapon_parts`の`recoil_distance`で表現できます(同梱の2両はこちらを使用)
- **補給**: 前提MODの車両メニューの補給ボタンは、武器設定ファイルで`Round`(弾倉)と`SuppliedNum`
  (1回の補給量)の両方が1以上の武器にだけ表示されます。`MaxAmmo`(弾倉を含めた総弾数)を省略すると
  弾数が無限になり補給の意味がなくなるため、あわせて指定してください。補給に必要なアイテムは
  `Item = <個数>, <iron_ingot / gunpowder / redstone>`で指定します。補給は停車中のみ行えます。
  同梱の3つの武器はいずれも設定済みです
- **HUD**: HUDスクリプトは車両ごとに1つで全座席共通です。運転者と砲手で表示を分けたい場合は、
  このアドオンが追加したHUD変数を使ってください

| 変数 | 内容 |
|---|---|
| `rail_seat` | 見ているプレイヤーの座席番号(0始まり。乗っていなければ-1) |
| `rail_is_driver` | 運転席に座っていれば1 |

同梱の装甲軌道車のHUD(`armored_railcar.txt`)は、運転席ではノッチと速度、砲手席では照準と武器の
状態を表示する例になっています。

## 線路装置(人力・レッドストーン)

分岐器・転車台・遷車台の操作と在線の検知を、ブロックで行えます。人力で操作する装置と、
レッドストーンで操作する装置を別々に用意しています。装置は設置すると、近く(16ブロック以内)の
対象に自動で連結します。連結先は測量ツールの連結モードで付け替えられます(装置から48ブロック以内)。

| 装置 | 種類 | 連結先 | 動作 |
|---|---|---|---|
| 転てつてこ | 人力 | 分岐器 | 右クリックで次の分岐方向へ切り替え |
| 転てつ機 | レッドストーン入力 | 分岐器 | 入力の強さで分岐方向を選ぶ(下記) |
| 転車台・遷車台操作盤 | 人力 | 転車台・遷車台 | 右クリックで次、スニーク+右クリック(素手)で前の停止位置へ |
| 転車台・遷車台制御器 | レッドストーン入力 | 転車台・遷車台 | 入力の強さnで、n番目の停止位置へ(0では動かさない) |
| 在線検知器 | レッドストーン出力 | 線路区間 | 区間に車両がいる間、強さ15を出力 |
| 信号機 | レッドストーン入力 | なし | 入力の強さで現示が変わる(下記) |
| 踏切遮断機 | レッドストーン入力 | なし | 入力がある間、遮断かんを下ろして警報灯を点滅させ、警報音を鳴らす |

- **転てつ機**: 入力0で0番目、1以上でその番号の分岐方向(分岐の数を超える場合は最後)に開通します。
  2方向の分岐器なら「入力なし=基本の方向、入力あり=分かれる方向」になります。基本の方向(0番目)は、
  端から作った分岐なら2点目への線路、線路の途中から作った分岐なら元の線路の続きです
- **制御器**: 停止位置の順番は、転車台は1点目(作成時)の方向から角度順、遷車台は横方向の位置順です。
  桁と線路にまたがっている車両がある場合や、動作中は動きません
- レッドストーン装置は入力が **変化したとき** に動作します。設置時や読み込み時の入力では動作しません
- 人力装置も、測量ツールを持っているときは操作されません(ツールの操作が優先されます)
- 在線検知器は、車両の中心または前後の台車が区間に載っているかで判定します
- **信号機**: 入力0で進行(緑)、1〜7で注意(黄)、8〜15で停止(赤)。灯火は上から緑・黄・赤で、
  設置したプレイヤーの方を向きます。点灯中の灯火は夜間でも光って見えます。支柱を兼ねた形なので、
  下にフェンスなどを積むと背の高い信号機になります。在線検知器の出力をそのままつなぐと、在線中は停止現示です
- **踏切遮断機**: 警報灯は設置したプレイヤーの方を向き、遮断かん(4ブロック)は警報灯の方から見て
  右側へ伸びます。道路の両側に向かい合わせに置くと、両方から道路を塞げます
- 信号機の現示は今のところ表示だけで、列車を自動で止める機能(ATS)はありません

## 鉄道車両

「鉄道車両」スポーンアイテム(T1〜T5)で、前提MODと同じ車両選択画面から呼び出せます。
線路の近く(6ブロック以内)に呼び出すと自動で線路に載ります。向きは呼び出したときの
プレイヤーの向きに近い方になります。

- W / S: ノッチ(またはスロットル)の操作
- ブレーキ: 前提MODのブレーキキー

**視点**: 運転席の視点は、前提MODの航空機などと同じ仕組み(FreeCameraVehicle)で車両の向き・傾きに
完全に連動します。カーブでの向きの変化やカント(傾き)がそのまま視点に反映されます。前提MODの
フリールックキーで、一時的に視点を切り離して周囲を見回せます(キーを離すと車両の向きへ戻ります)。

**ノッチ式**: 車両JSONの `rail` で `power_notches`(前進側)・`reverse_notches`(後進側)を指定すると、
W / S を押すたびにノッチが1段ずつ動きます(押し続けると一定間隔で進みます)。各段の目標値はノッチ数で
等分され、スロットル(ハンドル位置)は前提MODの `throttle_up_down` の速さで目標値へ動きます。
どちらも0(省略)なら、前提MODと同じスロットル式です。

**加減速**: 前提MODの共通項目 `acceleration`(追従度)・`max_speed` を使います。スロットル(ノッチの目標値)に
応じた目標速度(スロットル × 最高速度)へ `acceleration` の割合で近づくので、ノッチの段ごとに到達する
速度が決まります。ノッチを下げる・切にすると減速はせず惰行し、走行抵抗(`resistance`)で少しずつ
速度が落ちます。止めるにはブレーキ(`brake`)を使います。

**運転HUD**: 前提MODのHUDをそのまま使います(速度・燃料なども前提MODの値)。テスト車両には、スロットルを
マスコンのハンドル位置として目盛り(P7〜P1・N・R1〜R2)の上に表示するHUDスクリプト `railcar_notch`
(`assets/railwayvehicleaddon/hud/railcar_notch.txt`)を指定しています。別のノッチ数の車両には、この
スクリプトを複製して目盛りの行とハンドル位置の式を書き換えてください。

**石炭・水(蒸気機関車)**: 前提MODの`HudVariableProvider`(HUDスクリプトにアドオン独自の変数を
追加できる仕組み。tudursvehiclemod 1.0.4以降が必要)を使って、蒸気機関車向けに次の変数を追加しています。

| 変数 | 内容 |
|---|---|
| `rail_fire_seconds` | 火室の残り燃焼時間(秒) |
| `rail_coal_count` | インベントリに残っている石炭・木炭・石炭ブロックの個数(ブロックも1個として数える) |
| `rail_low_coal` | 火室が空で石炭も残っていないとき、`low_fuel`と同じ速さで0/1に点滅 |

水位は前提MODの`fuel`/`max_fuel`/`low_fuel`をそのまま水として流用しているため、新しい変数は
ありません。これらは`power_source`が`steam`の車両でだけ値が入り、気動車・電車では常に0です。
`railcar_throttle`(蒸気機関車用HUD)で表示例を確認できます。

**動力**(`rail.power_source`):

| 値 | 動力 | 補給 |
|---|---|---|
| `fuel`(既定) | 前提MODの燃料(気動車など) | 前提MODの燃料補給 |
| `steam` | 石炭・木炭(石炭ブロック)と水 | 石炭は車両のインベントリへ入れる(`inventory_size` が必要)。水は前提MODの燃料を水として使い、給水塔の近くに停車すると補給される |
| `electric` | 電化区間からの給電(下記の変電所が必要) | 給電されている電化区間(架線・第三軌条のどちらでも可)を走っている間だけ力行できる。前提MODの燃料は使わないので `fuel_consumption` に `-1` を指定する |

- 蒸気機関車は、石炭1個(木炭も同じ)で出力100%のまま約80秒走れます(出力が小さいほど長持ちします)。
  石炭ブロックはその10倍です。火室の石炭が尽きると自動で次の1個をくべます
- 電車は、車両(中心・前後の台車のいずれか)が電化区間にあれば給電されます。給電がない・石炭がないときは
  ハンドルは動かせますが力行できず、アクションバーに知らせが出ます

**給水塔**: 水平5ブロック以内に停車している蒸気機関車へ水を補給します(約25秒で満タン)。

**変電所**: 電化区間に電気を供給します。設置すると近く(16ブロック以内)の線路区間に自動で連結し、
連結先は測量ツールの連結モードで付け替えられます。右クリックでGUIが開き(測量ツールを持っているときは
連結モードの操作が優先されます)、燃料スロットに石炭・木炭・石炭ブロックを入れると、かまどのように
1つずつ燃やして発電します(バニラのかまどと同じ燃焼時間。石炭ブロックは石炭の10倍)。燃料が尽きると
停止し、入れると再び動きます。壊すと燃料スロットの中身が落ちます。

GUIでは、燃料スロットのほか、次の状況を確認できます。

- 今燃えている燃料の残り(バーと残り秒数)、稼働中か停止中か
- 供給能力(同時に何両分か)と、連結先の給電区画の現在の給電(混雑していると100%を下回ります)
- 連結先の座標。連結されていない場合、連結先が電化されていない場合はその旨を警告表示します

連結した区間を含む「つながった電化区間のまとまり」(デッドセクション、つまり電化されていない区間を
挟むと別のまとまりになります)に、稼働中は供給能力(目安として同時に3両分)を提供します。そのまとまりで
同時に力行している電車の数が供給能力を超えると、供給能力を電車の数で割った分だけ力行が弱まります
(鉄道模型の電源装置のように、つなぎすぎると全体の出力が落ちるイメージです)。変電所が1つも稼働して
いないまとまりでは、電車は力行できません。架線・第三軌条は見た目だけで電気を流すわけではないので、
変電所はその真下や真横でなくても、その電化区間に連結してさえいれば機能します。

**編成の加速(予定)**: 連結(編成)の実装時に、`rail.mass`(重さ、既定1.0)を使って編成全体の加速を決める
予定です。考えている方式は「編成の追従度 = 動力車の(acceleration × mass)の合計 ÷ 全車両のmassの合計」で、
重い客車・貨車をつなぐほど、動力車を増やすほど加速が変わります。単車では加速に影響しません。

テスト用に次の4両を同梱しています。

| 車両 | 動力 | ノッチ | 用途 |
|---|---|---|---|
| `railwayvehicleaddon:sample_railcar` | fuel(前提MODの燃料) | 前進7・後進2 | 気動車の例 |
| `railwayvehicleaddon:sample_steam_locomotive` | steam(石炭・木炭+水) | 連続スロットル | 蒸気機関車の例。インベントリ8枠 |
| `railwayvehicleaddon:sample_electric_train` | electric(架線) | 前進5・後進1 | 電車の例。屋根にパンタグラフの飾りあり |
| `railwayvehicleaddon:sample_passenger_car` | なし(動力無し) | − | 編成(連結)機能のテスト用の客車。運転席が無いため単独では動きません |
| `railwayvehicleaddon:sample_armored_railcar` | fuel | 前進5・後進1 | 装甲軌道車(武装のテスト用。後述の「武装」を参照) |
| `railwayvehicleaddon:sample_railway_gun` | なし(動力無し) | − | 列車砲(武装のテスト用。機関車に連結して運ぶ) |

### 車両JSONの `rail` オブジェクト

前提MODの車両JSONに `rail` オブジェクトを追加すると、鉄道車両固有の設定になります
(前提MODの読み込みは未知のキーを無視するため、同じファイルに書けます)。
`entity_type` は `railwayvehicleaddon:rail_vehicle` を指定してください。

```json
"entity_type": "railwayvehicleaddon:rail_vehicle",
"rail": {
  "bogies": [
    { "part": "$bogie_front", "pivot_x": 0.0, "pivot_y": 0.35, "pivot_z": 3.2 },
    { "part": "$bogie_rear",  "pivot_x": 0.0, "pivot_y": 0.35, "pivot_z": -3.2 }
  ],
  "brake": 0.015,
  "resistance": 0.0003,
  "grade_gravity": 0.04,
  "power_notches": 7,
  "reverse_notches": 2,
  "mass": 1.0,
  "power_source": "fuel",
  "coupler_front": 4.5,
  "coupler_rear": -4.5
}
```

| 項目 | 既定値 | 説明 |
|---|---|---|
| `bogies` | 空 | 台車。`pivot_z` が最大のものを前台車、最小のものを後台車として線路に載せます(`pivot_z`×`scale`が線路上の位置)。`part` を指定するとそのOBJグループがカーブで回転します。省略時は前後±1ブロックで線路に載せます |
| `brake` | 0.015 | ブレーキ時の減速度(ブロック/tick²) |
| `resistance` | 0.0003 | 走行抵抗による減速度(ブロック/tick²) |
| `grade_gravity` | 0.04 | 勾配にかかる重力加速度。勾配を掛けた分が加減速になります |
| `power_notches` | 0 | 前進側のノッチ数。前進・後進とも0ならスロットル式 |
| `reverse_notches` | 0 | 後進側のノッチ数 |
| `mass` | 1.0 | 重さ(編成の実装時に加速の計算に使う予定) |
| `power_source` | `fuel` | 動力(`fuel` / `steam` / `electric`) |
| `coupler_front` | 未指定(台車の位置を使う) | 連結器の位置(モデル座標のZ、前側)。車体が台車より外側へ張り出す車両では、車体の実際の前端に合わせて指定する(未指定だと連結時に車体が重なって見える) |
| `coupler_rear` | 未指定(台車の位置を使う) | 連結器の位置(モデル座標のZ、後側)。扱いは`coupler_front`と同じ |

最高速度は前提MODの `max_speed`(ブロック/tick)、加速の追従度は `acceleration`(既定0.05)、ハンドル(スロットル)の
動く速さは `throttle_up_down` が使われます。テスト車両は `acceleration` 0.02、`throttle_up_down` 2.0 です。モデルは原点を
**レール上面**、前方を **+Z** として作成してください。

## 設定(`config/railwayvehicleaddon.json`)

サーバー側の値がログイン時にクライアントへ送られ、プレビューにも使われます。

| 項目 | 既定値 | 説明 |
|---|---|---|
| `gauge` | 1.435 | 軌間(ブロック) |
| `min_curve_radius` | 12.0 | 最小曲線半径 |
| `max_grade` | 0.1 | 最大勾配(0.1 = 100‰) |
| `vertical_curve_length` | 16.0 | 縦曲線の長さ(0で縦曲線なし) |
| `clearance_half_width` | 1.5 | 建築限界の片側幅 |
| `clearance_height` | 4.0 | 建築限界の高さ |
| `unbreakable_hardness` | 30.0 | この硬度以上のブロックは自動撤去不可(黒曜石=50、古代の残骸=30) |
| `design_speed_kmh` | 80.0 | カント計算に使う設計速度。低くするとゆるい曲線のカントが小さくなります |
| `cant_transition_length` | 16.0 | カントの逓減長。直線や別の曲線とのつなぎ目で、カントをこの長さをかけて滑らかに変化させます |
| `track_render_distance` | 256.0 | 線路の最大描画距離(ブロック)。チャンク表示距離を超える値は切り詰められます。0以下でチャンク表示距離に従います |
| `max_waypoints` | 64 | 1回の敷設の最大経由点数 |
| `max_route_length` | 2048.0 | 1回の敷設の最大延長 |
| `drop_removed_blocks` | `player_placed` | 撤去したブロックのドロップ(サバイバル時のみ): `none` / `player_placed` / `all` |

### 自然地形の判定

自然の地形とみなすブロックはブロックタグ `railwayvehicleaddon:natural_terrain` で
定義しています。データパックで追加・変更できます。村などの生成構造物に使われている
木材やレンガは「設置物」として警告されます(敷設は可能です)。

## フェーズ1の制限事項

- 信号・編成(連結)・自動運転は未対応です
- チャンクの強制ロードは未実装です(編成を扱うフェーズ2で、動作中の編成全体と前方を強制ロードする方式で実装予定)
- 敷設・撤去の対象はロード済みの範囲に限られます
- 既存線路の端に接続した箇所には縦曲線が入らず、勾配が異なると折れ角が残ります
- 列車とエンティティの衝突判定はありません(すり抜けます)
- バニラのレール・トロッコとの互換はフェーズ3で対応予定です
